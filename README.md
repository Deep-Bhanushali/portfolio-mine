# Deep Bhanushali Portfolio

Cyber-styled React portfolio for Deep Bhanushali, built with Vite, TypeScript, Tailwind CSS, Framer Motion, and lucide-react.

## Links

- Portfolio: https://deep-bhanushali.vercel.app
- GitHub: https://github.com/Deep-Bhanushali
- LinkedIn: https://www.linkedin.com/in/deep-bhanushali-73307a341
- LeetCode: https://leetcode.com/u/DeepBhanushali24/

## Getting Started

1. Install dependencies: `npm install`
2. Start local development: `npm run dev`
3. Build for production: `npm run build`
